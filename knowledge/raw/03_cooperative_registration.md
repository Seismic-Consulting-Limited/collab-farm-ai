# # CollabFarm Cooperative Registration Guide

## Overview

Cooperatives must be approved before they can operate on the CollabFarm platform.

The registration and approval process ensures that only legitimate cooperatives can manage farmers and participate in agricultural funding activities.

## Cooperative Approval Process

The cooperative registration process involves:

1. Cooperative registration submission.
2. Super Admin review.
3. Cooperative approval, rejection, or request for changes.

## Super Admin Review

The Super Admin reviews pending cooperatives.

The review includes:

- Cooperative details.
- Cooperative documents.
- Registration information.

The Super Admin can:

- Approve the cooperative.
- Reject the cooperative.
- Request changes.

The cooperative is notified of the decision.

## After Approval

Once approved, the Cooperative Admin can access cooperative features.

The Cooperative Admin can then:

- Manage the cooperative profile.
- Add farmers.
- Submit farmer information.
- Add farm information.
- Create farming cycles.
- Choose or create funding packages and submit them for review.
- Track funding activities.

## Cooperative Access Status

Cooperative access is controlled by approval status.

- Approved cooperatives can access cooperative features.
- Unapproved or suspended cooperative users cannot access cooperative functionality.
